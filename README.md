# TaskFlow

یه اپ مدیریت تسک (شبیه Trello ساده) برای یادگیری و رزومه فرانت‌اند.

## نقشه راه (به ترتیب پیاده‌سازی)
- [ ] فاز ۱ — Git & راه‌اندازی پروژه
- [ ] فاز ۲ — Board اولیه + Data Flow (props, lifting state up)
- [ ] فاز ۳ — Hooks (useEffect, custom hooks, useContext)
- [ ] فاز ۴ — Component Composition (Modal, Card, Button)
- [ ] فاز ۵ — اتصال به Rest API (json-server)
- [ ] فاز ۶ — State Management (TanStack Query + Zustand)
- [ ] فاز ۷ — Refactor با اصول Clean Code / SOLID
- [ ] بونس — نسخه React Native با Expo

## چطور اجرا کنم؟
```bash
npm install
npm run dev        # اجرای فرانت روی localhost:5173
npm run server      # اجرای فیک بک‌اند (json-server) روی localhost:3001
```
